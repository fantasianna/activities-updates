# Activities

Обновления Android-приложения Activities: APK и `version.json` в последнем релизе. С версии 0.8
приложение само смотрит сюда и предлагает обновиться.

Поставить в первый раз: на телефоне открыть
[последний релиз](https://github.com/fantasianna/activities-updates/releases/latest), скачать
`activities.apk` и разрешить установку.
